# Fixed-`S0` Construction-Space Screen

## Result

No current-contract fixed-field construction witness survives.

The active CL-001 contract requires the evaluator index to compare the named
disjoint retail populations: US/Argentine for the dollar arm and US/Salvadoran
for the Bitcoin arm. Those comparisons necessarily carry the jurisdictional,
policy, access, wallet, subsidy, banking, exchange, and time surfaces already
recorded in the active evaluator dossiers. Statistical adjustment can model
those differences; it cannot make the underlying enforcement construction the
same.

The strongest alternatives either replace the named populations, retype
`i` from retail population to analytic observer, cease to be disjoint, or hold
the result fixed by simulation. Each is a possible ingredient of a new
preregistration, but none clears the committed experiment.

This is a class-relative construction result about the current ratified
contract and current evidence. It is not a universal impossibility theorem, a
gate score, a CL-001 verdict, or a choice of replacement design.

## Witness Contract

A positive witness for one arm would have to satisfy all of these at once:

1. preserve the arm's named disjoint retail populations;
2. change evaluator index `i`;
3. hold `R0`, `K0`, `S0`, `M0`, `T`, `B`, `M1`, and `Omega` fixed;
4. hold target population, jurisdiction, policy time, access path, and every
   outcome-relevant institutional import fixed;
5. measure an actually binding constraint class and exit-cost interval rather
   than an observer label or stipulated model output; and
6. preserve the two-outcome preregistration without repairing the frame after
   the defect became visible.

The tension is at clauses 1 and 4. Under the named comparisons, changing the
retail population changes the target jurisdiction and institutional
construction. Removing that difference also removes the named comparison.

### Losses And Imports

The current defect is constructive, not merely statistical. The compared
populations occupy different legal and operational systems. A regression,
matching score, reweighting scheme, or post-hoc control variable can state a
counterfactual conditional on modeled sufficiency. It cannot make the same
law, rails, wallets, subsidies, exchange permissions, remedy paths, and policy
date operate on both populations.

Using such an estimate as the fixed-`S0` result would import the adjustment
model as a hidden completion burden and would leave the charter's declared
causal fields unfixed. This screen therefore does not rank statistical methods;
it records why none is a construction witness for the current named pairs.

| Loss or import | Applies to field | Current burden |
|---|---|---|
| Cross-national legal and operational context | `S0`, `T`, `B`, `I`, `N`, `V` | It changes with the named population pairs and cannot be removed by relabeling it as context. |
| Adjustment-model sufficiency | `I`, `L`, `V` | Reweighting imports the assumption that measured covariates close every outcome-relevant path. |
| Analytic-panel representation | `M0`, `P`, `V` | A frozen packet holds evidence fixed but changes the measured object from retail constraint to observer classification. |
| Simulation stipulation | `K0`, `S0`, `T`, `B`, `V` | The model fixes the construction by assumption and therefore cannot witness the target systems. |

No move is discarded as scientifically useless. Each is classified by whether
it can instantiate the current contract.

### What This Source Does Not Establish

This screen does not establish that every possible replacement design fails. It
does not establish which co-varying mechanism would move a measured result,

### Falsifiers And Reopen Conditions

This screen is overturned if a later source supplies a positive construction
that:

- keeps one of the named cross-national population pairs;
- demonstrates common jurisdictional and operational enforcement surfaces,
  not merely protocol similarity or a statistical adjustment;
- holds `S0`, `T`, `B`, policy time, access, and all outcome-relevant imports
  fixed;
- changes only evaluator `i`; and
- measures the binding constraint class and exit-cost interval without
  observer/source conflation.

A separately preregistered replacement does not falsify this screen. It
supersedes the current experiment by changing the contract explicitly, which
is the admissible route after Frame Discipline exposed the defect.

## Operational Consequence

The active fixed-field-witness alternative is closed for the committed
US/Argentina and US/El Salvador construction. Packet population remains
closed. The remaining route back to a runnable CL-001 is a frame-holder choice
and separately committed preregistration of a replacement evaluator design.

The strongest replacement family visible from this screen is within-context
matched strata, with blinded analytic panels retained only as a
measurement-bias control. That ranking is advisory evidence for the frame
holder, not an owner decision made by this Run.
